# Casper

**Your Telegram. Your rules.**

Неофициальный клиент Telegram для iPhone на Swift и SwiftUI
с отдельным разделом Casper: приватность присутствия, локальный архив
сообщений и локальный Voice Changer.

</div>

---

## 1. Что такое Casper

Casper — сторонний клиент Telegram для iPhone. Вы входите в свой обычный аккаунт
Telegram и пользуетесь своими чатами, группами и каналами. Поверх обычного клиента
появляется раздел **Casper** с дополнительными настройками.

Три принципа, на которых держится проект:

1. **Только реальные возможности.** Casper работает через официальную библиотеку
   Telegram — TDLib. Никаких «внутренних» серверных функций, недоступных сторонним
   клиентам, здесь нет и быть не может. Где Telegram, iOS или Apple что-то не
   позволяют, это написано прямо в интерфейсе и в [docs/LIMITATIONS.md](docs/LIMITATIONS.md).
2. **Никаких секретов в репозитории.** Ключи Telegram, сертификаты и токены живут
   в GitHub Secrets и в Keychain устройства — см. [docs/SECRETS.md](docs/SECRETS.md).
3. **Разработка с iPhone.** Код правится с телефона, а компилирует macOS-раннер
   GitHub Actions — см. [docs/IPHONE-WORKFLOW.md](docs/IPHONE-WORKFLOW.md).

Casper **не** является форком официального приложения Telegram для iOS. Весь
интерфейс написан с нуля на SwiftUI. Подробности о лицензиях — в [NOTICE.md](NOTICE.md).

## 3. Что в разработке

- Настоящие голосовые сообщения: нужен кодировщик **Opus** и контейнер **OGG**
  (требование Telegram). Пока обработанный звук уходит как аудиофайл.
- Аватары, фото, видео, файлы, ответы, пересылка, реакции.
- Push-уведомления через TDLib.
- Точечные исключения приватности по конкретным людям.

План по этапам: [docs/ROADMAP.md](docs/ROADMAP.md).

## 4. Раздел Casper

```
⚙️ Настройки
   └── Casper
        👻 Призрак                — контроль отображения присутствия
        🗑 Удалённые сообщения    — локальные копии полученных сообщений
        📴 Офлайн                 — кто видит «был(а) в сети»
        🎙 Voice Changer          — 6 эффектов, всё локально
        🔑 Интеграции             — свой ключ внешнего сервиса
        🎨 Внешний вид            — тема, акцент, пузыри
        ℹ️ О Casper
```

### 👻 Призрак — как это работает на самом деле

Сервер Telegram узнаёт о вашей активности **только из запросов вашего клиента**:
опция `online`, метод `viewMessages` для отметок о прочтении, `sendChatAction`
для «печатает…». Призрак просто не отправляет эти запросы. Это законное поведение
клиента, а не обход защиты.

**Чего сделать нельзя:** быть онлайн для одних и офлайн для других (флаг один для
всех) и скрывать онлайн-статус выборочно. Точечные исключения возможны только для
настройки «был(а) в сети» — она серверная и живёт в разделе «Офлайн».

### 🗑 Удалённые сообщения — границы функции

Casper хранит в своей локальной базе те сообщения, которые приложение **уже
получило**, и помечает их, когда Telegram сообщает об удалении. Достать с сервера
сообщение, которого приложение не получало, невозможно — его там больше нет.
Секретные чаты не архивируются принципиально. Функция по умолчанию выключена,
есть срок хранения и полная очистка.

### 🎙 Voice Changer — без внешних сервисов

Обработка идёт на устройстве через AVAudioEngine: сдвиг тона, эквалайзер и
фабричные пресеты искажения Apple. Звук никуда не загружается, **API-ключ для
этого не нужен**. Раздел «Интеграции» оставлен для другого — расшифровки и перевода
голосовых через сервис, ключ которого вы добавляете сами.

и генерируется XcodeGen. YAML можно править с телефона, `.pbxproj` — нельзя.

## 6. Установка зависимостей

Для работы с проектом на iPhone ничего устанавливать не нужно.

На macOS-раннере GitHub Actions всё ставится само:

```bash
brew install xcodegen          # генератор Xcode-проекта
bash Scripts/fetch-tdlib.sh    # готовый TDLib XCFramework
```

TDLib берётся готовым из релизов [Swiftgram/TDLibFramework](https://github.com/Swiftgram/TDLibFramework)
(версия по умолчанию `1.8.67-d1085f9c`), компилировать его не нужно.

## 7. Как собрать проект

```bash
bash Scripts/fetch-tdlib.sh        # необязательно: без него будет демо-режим
bash Scripts/generate-project.sh   # создаст CasperTelegram.xcodeproj
bash Scripts/ci-test.sh            # сборка и тесты на симуляторе
```

- TDLib найден → полный режим, настоящий Telegram.
- TDLib не найден → демо-режим на `MockTelegramService`: интерфейс работает на
  придуманных данных, вход по любому номеру с кодом `12345`.

Подробно, включая частые ошибки: [docs/BUILD.md](docs/BUILD.md).

## 8. Как настроить Telegram API

1. Откройте [my.telegram.org](https://my.telegram.org) → **API development tools**.
2. Создайте приложение и скопируйте `api_id` и `api_hash`.
3. Добавьте их в GitHub Secrets как `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
4. Запустите сборку заново.

Без ключей приложение честно покажет экран «Нужны ключи Telegram» вместо входа.
Пошагово с iPhone: [docs/TELEGRAM-API.md](docs/TELEGRAM-API.md).

## 9. Как настроить дополнительные сервисы

Раздел **Casper → Интеграции** принимает адрес OpenAI-совместимого API и ваш ключ.
Ключ сохраняется в Keychain устройства, кнопка «Проверить» делает реальный запрос
списка моделей. Ключ разработчика в приложение не встроен и в репозиторий не попадает.

## 10. Как пользоваться GitHub Actions

| Workflow | Когда запускается | Что делает |
|---|---|---|
| **CI** | автоматически на каждый push в `main` | генерирует проект, собирает, гоняет тесты |
| **Release → TestFlight** | вручную, кнопкой | подписывает, собирает IPA, выгружает в TestFlight |
| **TDLib check** | вручную | проверяет, что версия TDLib скачивается корректно |

Запуск с iPhone: вкладка **Actions** → нужный workflow → **Run workflow**.
Логи и ошибки читаются там же.

## 11. Какие нужны ключи и секреты

| Секрет | Для чего |
|---|---|
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | подключение к Telegram |
| `APPLE_TEAM_ID` | подпись приложения |
| `IOS_DIST_CERT_P12_BASE64`, `IOS_DIST_CERT_PASSWORD` | сертификат распространения |
| `IOS_PROVISIONING_PROFILE_BASE64`, `IOS_PROVISIONING_PROFILE_NAME` | профиль подписи |
| `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8_BASE64` | выгрузка в TestFlight |

Ничего из этого в репозитории нет и быть не должно. `.gitignore` уже блокирует
`*.p12`, `*.p8`, `*.mobileprovision`, `.env` и сгенерированный файл с ключами.
Инструкция: [docs/SECRETS.md](docs/SECRETS.md).

## 12. Ограничения iOS, Telegram и Apple

Коротко, без иллюзий:

- **iPhone не компилирует iOS-приложения.** Нужен macOS с Xcode — эту работу
  делает GitHub Actions.
- **Для установки на свой iPhone** практичен только платный Apple Developer
  Program и TestFlight. Внутренние сборки TestFlight не проходят ревью Apple.
- **Онлайн-статус нельзя скрывать выборочно** — флаг один для всех.
- **Скрыв своё «был(а) в сети»**, вы перестаёте видеть его у других: правило Telegram.
- **Удалённое до получения** восстановить невозможно.
- **iOS усыпляет приложения**, поэтому часть событий пройдёт мимо Casper.
- **Настоящее голосовое сообщение** требует Opus/OGG — это отдельный этап работы.
- **Регистрацию нового аккаунта** сторонний клиент делать не должен, только вход.

Полный разбор: [docs/LIMITATIONS.md](docs/LIMITATIONS.md).
