# Ограничения

Самый честный документ проекта. Здесь прямо написано, что Casper умеет, что умеет
частично и чего не может в принципе — и почему. Никаких обещаний сверх того, что
реально позволяет Telegram, Apple и физика (сон приложения в iOS).

## iPhone и сборка

| Функция | Статус | Почему | Что делаем вместо |
|---|---|---|---|
| Скомпилировать приложение прямо на iPhone | Невозможно | iOS не даёт запускать компилятор Swift/Xcode для сборки iOS-приложений | Компилирует GitHub Actions на `macos-latest`-раннере; с iPhone — правка кода, коммиты, запуск сборки, чтение логов ([IPHONE-WORKFLOW.md](IPHONE-WORKFLOW.md)) |
| Редактировать `.xcodeproj` с iPhone | Невозможно | `.pbxproj` — бинарно-подобный формат, не предназначен для правки в текстовом редакторе | Проект описан в `project.yml` (обычный YAML) и генерируется `XcodeGen`, `.xcodeproj` не хранится в git |

## Установка на свой iPhone

| Функция | Статус | Почему | Что делаем вместо |
|---|---|---|---|
| Установить сборку без Apple Developer Program | Работает частично | Бесплатная подпись живёт 7 дней и требует Mac с кабелем | Apple Developer Program ($99/год) → TestFlight, см. [INSTALL-IPHONE.md](INSTALL-IPHONE.md) |
| Ставить обновления через TestFlight | Работает | Внутренние тестировщики (сам разработчик, до 100 устройств) не проходят ревью Apple | — |
| Публикация в App Store | Работает частично | Проходит ревью Apple, это отдельная история для сторонних Telegram-клиентов | Для личного использования достаточно TestFlight |

## «Призрак»

| Функция | Статус | Почему | Что делаем вместо |
|---|---|---|---|
| Не отправлять «в сети» | Работает | Сервер узнаёт об активности только из исходящих запросов клиента (`setOption online`); это законное поведение клиента, а не обход защиты | `PresencePolicy` + `PresenceController` просто не шлют такие запросы |
| Не отправлять «прочитано» | Работает | Тот же принцип, метод `viewMessages` | Не вызывается, пока Призрак активен |
| Не отправлять «печатает…» | Работает | Тот же принцип, метод `sendChatAction` | Не вызывается, пока Призрак активен |
| Расписание Призрака | Работает | Пересчитывается при запуске и при возврате приложения в активное состояние | `GhostSettings.isActive(at:)` |
| Расписание, пока приложение усыплено iOS | Невозможно | iOS не даёт коду работать в фоне бесконечно | Не критично: пока Casper не работает, вы и так не в сети — сигналов никто не шлёт |
| Быть онлайн для одних и офлайн для других | Невозможно | Флаг «в сети» в Telegram один, общий для всех контактов | Точечные исключения доступны только для настройки «был(а) в сети» (раздел «Офлайн») |
| Скрыть «в сети» выборочно от конкретных людей | Невозможно | В Telegram API нет такого правила для онлайн-статуса | То же — используйте «был(а) в сети» с исключениями |
| Узнать, кто смотрел ваш профиль | Невозможно | Такого метода нет в Telegram API вообще, ни у одного клиента | — |

## «Офлайн» (был(а) в сети)

| Функция | Статус | Почему | Что делаем вместо |
|---|---|---|---|
| Скрыть «был(а) в сети» от всех / контактов / всех кроме списка | Работает | Серверная настройка `setUserPrivacySettingRules(userPrivacySettingShowStatus)` с правилами `AllowAll` / `AllowContacts` / `RestrictAll` / `AllowUsers` / `RestrictUsers` | Работает всегда, даже когда Casper закрыт |
| Видеть точное время «был(а) в сети» у других, скрыв своё | Невозможно | Ограничение самого Telegram: скрыл — не видишь чужого | Клиент это обойти не может, ничего не делаем |

## «Удалённые сообщения»

| Функция | Статус | Почему | Что делаем вместо |
|---|---|---|---|
| Показать, что собеседник удалил сообщение | Работает | TDLib присылает `updateDeleteMessages`, Casper хранит свою копию в SQLite (`MessageArchive`) и помечает её удалённой | — |
| Достать с сервера уже удалённое сообщение | Невозможно | Его там больше нет — работает только с тем, что приложение уже получило | — |
| Отличить настоящее удаление от освобождения кэша TDLib | Работает | `updateDeleteMessages` содержит `from_cache`; `from_cache = true` — TDLib просто чистит локальный кэш, это игнорируется | — |
| Ловить удаления, пока приложение усыплено iOS | Работает частично | Часть удалений произойдёт мимо Casper, пока приложение не активно — это поведение системы, а не ошибка | — |
| Архивировать секретные чаты | Невозможно (сознательно) | В параметрах TDLib стоит `use_secret_chats: false` — Casper принципиально не подключает секретные чаты | — |
| Хранить архив бесконечно | Работает частично | По умолчанию функция выключена; есть срок хранения 1/3/7/30 дней и полная очистка | Настраивается в разделе «Удалённые сообщения» |

## Voice Changer

| Функция | Статус | Почему | Что делаем вместо |
|---|---|---|---|
| Обработка голоса (Robot, Deep, Alien, Electronic, Bass) | Работает | Полностью локально, `AVAudioEngine` в режиме `.offline` (`AVAudioUnitTimePitch`, `AVAudioUnitEQ`, `AVAudioUnitDistortion`) | Внешние сервисы не нужны |
| Отправить обработанный звук как настоящее голосовое сообщение с волной | Работает | Telegram требует Opus в контейнере OGG, моно (`inputMessageVoiceNote`) | Готово. Opus кодирует сама iOS через `kAudioFormatOpus` в AudioConverter (`OpusStreamEncoder`), контейнер OGG собирается вручную (`OggOpusWriter`), волна громкости — 100 значений по 5 бит (`TelegramWaveform`). Внешние библиотеки не нужны. Если кодек в системе недоступен, есть запасной путь — отправка аудиофайлом |
| Расшифровка/перевод голосовых | Работает частично | Нужен свой ключ OpenAI-совместимого сервиса (раздел «Интеграции»), Casper сам ИИ не считает | Ключ хранится в Keychain, проверка — реальный запрос `GET {baseURL}/models` |

## Правила Telegram и Apple, которые мы соблюдаем

- Свой `api_id` / `api_hash` с my.telegram.org — регистрация нового аккаунта через
  сторонний клиент не делается, только вход (см. [TELEGRAM-API.md](TELEGRAM-API.md)).
- Приложение называется «Casper», а не «Telegram»; в разделе «О Casper» прямо
  написано, что это неофициальный клиент.
- Логотип Telegram (белый самолётик на синем круге) не используется.
- Код проекта открыт.
- Casper не форкает официальное приложение Telegram-iOS (GNU GPL v2) — весь
  интерфейс написан с нуля на SwiftUI, к Telegram подключается только через
  официальный TDLib (Boost Software License 1.0).
